## 📖 نبذة عن المشروع

تطبيق ويب متكامل بلغة **PHP** وقاعدة بيانات **MySQL** لإدارة بيانات المستخدمين (CRUD)، تم استضافته على بنية سحابية متكاملة تشمل:

- **GitHub** لإدارة الإصدارات والعمل الجماعي.
- **InfinityFree** للاستضافة السحابية المجانية.
- **Google Drive + Colab** لمعالجة البيانات وتحليلها.
- **WordPress.com** لتوثيق المشروع.

## 📂 هيكل المشروع

crud-php-simple/
├── index.php # الصفحة الرئيسية (Read)
├── add.php # إضافة مستخدم (Create)
├── edit.php # تعديل مستخدم (Update)
├── delete.php # حذف مستخدم (Delete)
├── dbConnection.php # الاتصال بقاعدة البيانات
